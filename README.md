## 1. Project Overview

The **Scientific Evidence Research System** is an automated academic research engine and interactive desktop workstation. It accepts natural-language inquiries across medical, life science, and general scientific disciplines, constructs clinical search protocols (PICO frameworks), executes targeted multi-query retrieval against live academic repositories (**Europe PMC** and **CORE**), standardizes and deduplicates publications, downloads JATS XML full-text where available, extracts structured evidence claims with statistical metrics, scores methodological quality, detects directional contradictions between trials, and generates a structured synthesis report with provenance citations.

> [!NOTE]
> **Zero Hallucination Guarantee**: Every claim, hazard ratio, $p$-value, and conclusion generated by the workstation is anchored to a real, peer-reviewed publication with verified DOIs, PMIDs, or PMCIDs.

### 👥 Target Users & Real-World Use Cases
- **Clinical & Biomedical Researchers**: Rapid evidence lookup for drug interventions, dosages, adverse events, and comparative efficacy across randomized controlled trials.
- **Academic Evaluators & Scientists**: Systematic literature scoping, tracking consensus versus controversy across published studies.
- **Computer Science & Engineering Researchers**: Exploring state-of-the-art methodology developments across open-access papers.

## 2. Problem Statement

Modern scientific literature expands by millions of publications annually. Researchers facing specific questions (e.g., *"Does metformin reduce cardiovascular events in patients with type 2 diabetes?"*) encounter critical bottlenecks:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       CRITICAL RESEARCH CHALLENGES                          │
├──────────────────────────┬──────────────────────────┬───────────────────────┤
│ 1. Search Fragmentation  │ 2. Unseen Retractions    │ 3. LLM Hallucinations │
│ Literature split across  │ Retracted papers cited   │ Generic AI fabricates │
│ disparate databases      │ as active evidence       │ non-existent PMIDs    │
├──────────────────────────┼──────────────────────────┼───────────────────────┤
│ 4. Duplication Overhead  │ 5. Buried Statistics     │ 6. Silent Conflicts   │
│ Cross-source redundant   │ Critical p-values & CIs  │ Opposing trial results│
│ records with mixed IDs   │ hidden deep in text      │ smoothed over by LLMs │
└──────────────────────────┴──────────────────────────┴───────────────────────┘
```

This automated research workstation solves these challenges through live verified database querying, deterministic filtering, Oxford-style quality grading, and transparent claim-level extraction.

## 3. Objectives

- **Automate PICO Protocol Extraction**: Convert natural-language questions into structured dimensions (Population, Intervention, Comparator, Outcome, Dosage, Frequency, Condition).
- **Multi-Source Literature Retrieval**: Query live academic APIs (Europe PMC REST API and CORE v3 API) with intelligent source routing and synonym expansion.
- **Data Integrity & Deduplication**: Implement multi-tier matching (DOIs, PMIDs, and Jaccard title token similarity) and filter retracted publications.
- **Full-Text JATS XML Parsing**: Download and parse structured sections (`<sec>`, `<p>`, `<abstract>`) from open-access repositories.
- **Atomic Evidence Extraction**: Extract granular findings including effect directions (`positive`, `negative`, `neutral`), effect sizes (Hazard Ratios, Odds Ratios), and statistical info ($p$-values, 95% CIs).
- **Empirical Scoring & Question Matching**: Apply weighted relevance equations and Oxford-style study design hierarchies (Meta-Analyses down to Editorials).
- **Conflict Detection**: Group findings by outcome and flag directional disagreements without artificial majority voting.
- **Provenance & Interactive Visualization**: Stream progress via Server-Sent Events (SSE) and render an interactive desktop workstation with a 2D Canvas force-directed Knowledge Graph.

## 8. Literature & Paper Retrieval

The system interfaces with two premier academic literature repositories:

### 1. Europe PMC (Biomedical & Life Sciences)
- **Base Endpoint**: `https://www.ebi.ac.uk/europepmc/webservices/rest/search`
- **Full-Text Endpoint**: `https://www.ebi.ac.uk/europepmc/webservices/rest/{pmcid}/fullTextXML`
- **Coverage**: $>40\text{M}$ biomedical abstracts, full-text articles, preprints, and clinical guidelines.
- **Authentication**: Public access (No API key required).
- **Implementation**: Implements `cursorMark` token pagination, author affiliations, MeSH terms, and citation counts with a $0.4\text{s}$ polite rate limit.

### 2. CORE (Global Open Access Multidisciplinary Research)
- **Base Endpoint**: `https://api.core.ac.uk/v3/search/works`
- **Coverage**: Aggregates open-access research across computer science, physics, engineering, and mathematics.
- **Authentication**: Requires a free API key passed via `Authorization: Bearer <API_KEY>`.
- **Implementation**: Implements offset-based pagination and a $6.5\text{s}$ delay between requests to comply with free-tier quotas.

## 11. Relevance, Ranking & Quality Scoring

### A. Paper Relevance Scoring Formula
Implemented in `pipeline/relevance_ranker.py`, papers are scored ($0.0 - 1.0$) using weighted parameters configured in `config.py`:

$$\text{Relevance Score} = \left( w_{\text{kw}} \cdot S_{\text{kw}} + w_{\text{pico}} \cdot S_{\text{pico}} + w_{\text{type}} \cdot S_{\text{type}} + w_{\text{rec}} \cdot S_{\text{rec}} + w_{\text{ft}} \cdot S_{\text{ft}} + w_{\text{lvl}} \cdot S_{\text{lvl}} \right) \times M_{\text{status}}$$

| Weight Component | Symbol | Value | Description |
| :--- | :---: | :---: | :--- |
| **Keyword Relevance** | $w_{\text{kw}}$ | `0.30` | Harmonic mean ($F_1$-style) of token overlap between question and paper |
| **PICO Element Match** | $w_{\text{pico}}$ | `0.35` | Mean match score across Population, Intervention, Outcome, Condition, Dose |
| **Study Type Alignment**| $w_{\text{type}}$ | `0.10` | Match between study design and implied protocol preferences |
| **Publication Recency** | $w_{\text{rec}}$ | `0.05` | Recency decay ($1.0$ for $\le 2$ yrs, $0.85$ for $\le 5$ yrs, $0.70$ for $\le 10$ yrs) |
| **Full-Text Available** | $w_{\text{ft}}$ | `0.10` | Availability of complete full-text XML ($1.0$) vs abstract ($0.6$) |
| **Evidence Depth Level**| $w_{\text{lvl}}$ | `0.10` | Evidence depth classification (`full_text`=1.0, `abstract_only`=0.6) |
| **Status Multiplier** | $M_{\text{status}}$ | `1.0 / 0.85 / 0.5` | Penalty multiplier for corrected ($0.85$) or concern ($0.50$) status |

*Cutoff Threshold*: Papers scoring below `MIN_RELEVANCE_SCORE` ($0.15$) are discarded.

---

### B. Claim-Level Question Matching
Evaluates how directly an extracted finding applies to the user's protocol:
- **Intervention Match**: $25\%$
- **Outcome Match**: $20\%$
- **Population Match**: $15\%$
- **Dose Match**: $10\%$
- **Comparator Match**: $10\%$
- **Duration Match**: $5\%$
- **Study Design Match**: $5\%$
- **Bonuses**: $+5\%$ for clear effect direction, $+5\%$ for reported statistical metrics.

---

### C. Oxford Study Design Quality & Unified Score
- **Study Design Hierarchy**: Systematic Review / Meta-Analysis ($0.95$), RCT ($0.90$), Controlled Clinical Trial ($0.80$), Cohort Study ($0.65$), Case-Control ($0.55$), Cross-Sectional ($0.50$), Case Report ($0.30$), Editorial ($0.15$).
- **Statistical Precision**: Baseline $0.3$ + bonuses for 95% CIs ($+0.2$), $p$-values ($+0.15$), effect sizes (HR/OR/RR, $+0.15$), and sample sizes ($+0.1$).
- **Unified Score Formula**:
  $$\text{Unified Score} = 0.50 \times \text{Question Match Score} + 0.50 \times \text{Quality Score}$$

## 22. Security & Privacy Practices

- **Server-Side API Key Storage**: Keys (`CORE_API_KEY`) are kept in `.env` and injected into HTTP headers on the server side.
- **Input Sanitization**: Inquiries are validated against length limits ($10 - 2,000$ characters).
- **XSS Escaping**: All dynamic strings rendered in the DOM are escaped via `esc()`.
- **Local-First Privacy**: Searches and claim analyses using Ollama remain entirely on the local machine without sending private search data to external cloud AI providers.

---

## 23. Technical Limitations

- **CORE Free-Tier Limits**: Free CORE API keys permit $\sim 10\text{ requests/min}$, requiring a $6.5\text{s}$ throttle delay between requests.
- **XML Full-Text Availability**: JATS XML full text is available only for open-access Europe PMC articles with valid PMCIDs. Closed-access articles rely on abstracts.
- **Local Inference Hardware**: Local model execution requires adequate RAM/VRAM.

---

## 24. Innovation & Project Contribution

1. **Empirical Multi-Factor Scoring**: Replaces subjective LLM rankings with a formula weighting keyword $F_1$, PICO overlap, study hierarchy, and recency.
2. **Deterministic Retraction Filter**: Pre-empts citation of retracted papers before claim extraction occurs.
3. **Honest Conflict Detection**: Highlights opposing clinical trial findings rather than artificially averaging them out.
4. **Interactive 2D Physics Visualizer**: Dynamically maps questions, papers, PICO concepts, and findings on an interactive HTML5 Canvas.

## 25. Existing System vs. Proposed System

| Dimension | Generic LLM / Basic Search | Scientific Evidence Research System |
| :--- | :--- | :--- |
| **Citation Traceability** | Hallucinates non-existent PMIDs | Strict $1:1$ provenance to live DOIs & PMIDs |
| **Database Reach** | Single manual search portal | Multi-source querying across Europe PMC and CORE |
| **Deduplication** | Manual cross-checking required | Automated 3-tier DOI, PMID, and Title Jaccard matching |
| **Retraction Awareness** | Overlooked by researchers | Automated retraction and errata status detection |
| **Evidence Extraction** | Reading multi-page PDFs | Atomic claim extraction with statistical values |
| **Conflict Analysis** | Smoothed over or ignored | Explicit conflict grouping and discordance analysis |
| **Execution Feedback** | Static loading spinner | Real-time SSE stage progression timeline |

## 26. Performance Considerations

- **Abstract-First Processing**: Abstracts are parsed for initial claim extraction to minimize inference token latency, reserving full-text XML downloads for top-ranked papers.
- **Canvas HiDPI Optimization**: Knowledge Graph Studio dynamically matches `window.devicePixelRatio` with velocity damping to minimize CPU usage.
- **Sub-30-Second Turnaround**: Complete 15-stage research runs complete in $20 - 30$ seconds.
